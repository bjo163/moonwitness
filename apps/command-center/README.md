# MoonWitness Command Center (`apps/command-center`)

> **Tactical Governance, Administration & System Operations Terminal**  
> Built with Next.js 16 App Router, `@workspace/ui`, and `@moon/client`.

---

## 🛡️ Key Capabilities

- **Administrative CRUD Operations**: Hadith Compendiums, Quranic Verses, and Operator User Database with real API integration & resilient caching.
- **CAB Civilizational Governance**: RFC Voting, budget allocation, and covenant verification.
- **Universal Single Sign-On (SSO)**: Seamless cross-port session synchronization with `apps/web` (`mw_session` cookie).
- **Universal Command Palette**: Quick access to all admin tools (`Cmd+K`).

---

## 🚀 Running Locally

```bash
# Start Command Center on Port 3001
pnpm --filter command-center dev
```
