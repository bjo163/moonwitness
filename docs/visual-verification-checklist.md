# MoonWitness visual verification checklist

Verify each route in light, dark, and system modes at desktop and mobile widths.

## Public web portal

- [ ] `/` and `/home`
- [ ] Knowledge and observatory views
- [ ] Authentication screens
- [ ] Desktop navbar, search, notifications, and profile menu
- [ ] Mobile navigation and submenu behavior

## Command Center

- [ ] Dashboard, users, scriptures, and hadith
- [ ] Profile and settings
- [ ] Developer Console

## Review criteria

- [ ] Neutral background, card, popover, and border hierarchy is clear.
- [ ] Primary is reserved for actions, active states, focus, and key affordances.
- [ ] No white-on-white, black-on-black, or unreadable muted text.
- [ ] Loading, empty, error, dialog, dropdown, table, and chart states remain usable.
- [ ] Motion is purposeful and respects reduced-motion preferences.
- [ ] Tajweed colors appear only in Quranic visualization contexts.
