## Documentation Standards

All documentation follows MoonWitness [Research UI Guidelines](./guides/RESEARCH-UI.md):

- Sentence case for headings
- 65–75 character measure for prose
- Leading-relaxed line height
- Source attribution and provenance near relevant content
- Amiri font for Arabic passages

Run ode scripts/audit-rules.mjs to validate documentation compliance.
