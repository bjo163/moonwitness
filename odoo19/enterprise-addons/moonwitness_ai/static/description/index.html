MoonWitness AI Enhancement ========================== Extends the Odoo AI module with MoonWitness-specific features: * **MoonWitness Assistant Agent** — Domain-aware AI agent with custom system prompt for enterprise operations (projects, helpdesk, CRM, accounting). * **Custom Prompt Suggestions** — Quick prompt buttons tailored to MoonWitness workflows. * **Themed AI Chat** — AI chat window styling matching the MoonWitness Zinc design system (light + dark mode). Configuration ------------- 1. Go to **Settings → General Settings → Integrations** section. 2. Configure either an OpenAI API key or Google Gemini API key. 3. The MoonWitness Assistant agent is automatically created and available via the "Ask AI" systray button. Requirements ------------ * PostgreSQL with `pgvector` extension installed. * At least one LLM API key configured (OpenAI or Google Gemini).
